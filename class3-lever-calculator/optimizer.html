Methodology

Sampling

Each locked parameter is held fixed; each ranged parameter is drawn independently from a uniform distribution between its min and max on every sample. The generator is a seeded mulberry32 PRNG — the same seed and configuration always reproduce the same set of samples, so a good run can be re-derived exactly later.

Feasibility

Every sample runs through the same physics engine as the single-point calculator (physics.js). A sample is feasible if its geometry is valid, it stays a genuine class-3 ratio (L₁<R), its required rotation is within the constraint you set, its dead-center return math is defined, and any optional peak-deceleration / total-travel caps are met. Infeasible samples are discarded from ranking but counted in the summary.

Scoring & sort

For each active (weight>0) objective, values are min–max normalized across the feasible set, inverted (since every objective here is "smaller is better"), then combined as a weighted average. The ranked list is produced with the JS engine's native Array.prototype.sort — an O(n log n) comparison sort (TimSort/introsort hybrid depending on engine) — rather than a hand-rolled quadratic sort.

Pareto front

For whichever two objectives you pick to plot, the non-dominated frontier is found with the classic 2D skyline algorithm: sort by X ascending (O(n log n)), then sweep once tracking the best Y seen — a point joins the frontier exactly when it beats that running minimum. Total cost O(n log n), dominated by the sort.

Effort force range tags

Tag suitability ignores the effort force a row happened to sample. Instead, each feasible row's other parameters (arm lengths, masses, spring, dead-center offsets) are re-run through the physics engine at three points spanning each tag's range (min, mid, max), holding everything else fixed. A tag applies to that row only if all three points still pass every constraint — so a tag reflects the hardware configuration's robustness across that whole force band, not a lucky single sample.

Persistence uses the browser's IndexedDB — no server, no external database. CSV export is universal; the .xlsx export is a real OOXML workbook written by a small dependency-free zip/XML writer (shared/spreadsheet-export.js), not just a renamed CSV.
